ASEPAD - Sistema de Verificación de Certificados

Sistema de verificación de autenticidad para certificados en seguridad laboral. Arquitectura dockerizada desplegada en VPS con Nginx reverse proxy, base de datos PostgreSQL containerizada, y seguridad mediante Cloudflare Tunnels.

Arquitectura

Cloudflare Tunnel (Security Layer)
        ↓
   Nginx (Reverse Proxy)
        ↓
   ├─ Frontend Container (React)
   ├─ Backend Container (Node.js)
   └─ PostgreSQL Container (Database)

Impact

  • Emisión de certificados: de 1 semana → pocos minutos
  • +2,500 certificados emitidos y verificables en plataforma
  • Tiempo de búsqueda/verificación <200ms

Solución Implementada

  • Infraestructura 100% dockerizada en VPS
  • Nginx como reverse proxy para enrutamiento de contenedores
  • PostgreSQL containerizada para fácil migración/backup
  • Cloudflare Tunnels para acceso seguro sin exponer puertos
  • Sistema de códigos únicos con índices optimizados
Docker Nginx PostgreSQL Cloudflare React Node.js
